# Swag Labs Mobile - QA Testing Portfolio 📱

Repositorio de pruebas manuales, análisis de interfaz y listas de comprobación orientadas a la aplicación móvil de e-commerce **Swag Labs** (Android).

## 🚀 Descripción del Proyecto
Este proyecto forma parte de mi portafolio como **Bilingual QA Engineer**, enfocado en la aplicación de metodologías de pruebas exhaustivas en entornos móviles (emuladores de Android Studio), inspección de logs del sistema y diseño de listas de comprobación detalladas para asegurar la calidad del software (UI/UX, flujos funcionales y ciclo de vida de la aplicación).

## 📋 Contenido del Repositorio
* **`qa_mobile_swaglabs_completo.pdf`**: Lista de comprobación exhaustiva de 65 puntos que cubre:
  * Instalación y rendimiento inicial en emulador.
  * Pruebas funcionales de inicio de sesión (Login con escenarios positivos y negativos).
  * Validación de campos de texto, seguridad de contraseñas y caracteres especiales.
  * Navegación, catálogos, detalles de productos y carrito de compras.
  * Flujo completo de pago (*Checkout*) y confirmación de órdenes.
  * Pruebas de ciclo de vida (*App Lifecycle*), rotación de pantalla (*Landscape/Portrait*) y manejo de interrupciones.
  * Monitoreo técnico e inspección de errores en `Logcat`.

## 🛠️ Herramientas y Tecnologías Utilizadas
* **Entorno de Pruebas:** Android Studio (Emuladores virtuales).
* **Gestión y Ejecución:** Pruebas exploratorias y manuales orientadas a criterios de aceptación.
* **Depuración técnica:** Inspección de registros en tiempo real mediante `Logcat`.
* **Control de versiones:** Git y GitHub.
